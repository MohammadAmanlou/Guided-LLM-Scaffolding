# Data Availability

The materials publicly available in this repository include:

- the research-platform source code;
- the guided-use protocol and student-facing materials;
- orientation slides;
- productive and unproductive prompt examples;
- the transcript-coding codebook;
- selected de-identified interaction excerpts;
- study and model configuration information;
- analysis code implementing the statistical procedures reported in the paper;
- documentation of the expected private-data schemas and the mapping between
  manuscript results and analysis scripts.

The following participant-level or identity-linked study materials are not
publicly released:

- full raw chat transcripts;
- participant-level assessment and timing data;
- student identifiers and account records;
- original study-group assignment files;
- identity-level enacted-group reclassification mappings;
- independent annotator rating files;
- private transcript-coding/feedback records;
- attendance and assessment exports;
- uploaded participant answer sheets.

These materials are not publicly released because they contain learner
interaction, assessment, or identity-linked research data subject to privacy
and consent constraints.

The public analysis code can be used with authorized private inputs that follow
the documented schemas in
[`reproducibility/analysis/data_template/`](reproducibility/analysis/data_template/).

The publicly released reproducibility materials are intended to document the
study intervention, coding framework, representative interactions, analysis
procedures, and software configuration without exposing identifiable or
participant-level research data.
