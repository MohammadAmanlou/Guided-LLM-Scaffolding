# Reproducibility Materials

These materials accompany the paper
**“Beyond Access: Guided LLM Scaffolding for Independent Learning in Undergraduate Statistics”**
and document the guided-use intervention, coding framework, representative interactions,
study configuration, and analysis procedures.

## Materials

| File | Description |
|---|---|
| `guided_use_protocol.md` | Six-rule guided-use intervention and student-facing interaction protocol. |
| `student_guide.pdf` | Student-facing guide used to communicate the guided-use rules. |
| `instructions.pptx` | Orientation slides introducing the guided-use framework. |
| `prompt_examples.md` | Productive and unproductive prompt examples for the six rules. |
| `coding_codebook.md` | Human transcript-coding criteria and coding procedure. |
| `sample_transcripts.md` | Selected de-identified interaction excerpts with transcript-level coding examples. |
| `study_configuration.env.example` | Model and deployment configuration used for the study. |
| [`analysis/`](analysis/) | Analysis code, statistical procedures, manuscript-to-script mapping, and private-data templates used to reproduce the reported analyses. |
| [`../DATA_AVAILABILITY.md`](../DATA_AVAILABILITY.md) | Data-availability statement describing which study materials are public and which remain private. |

## Notes on Data Availability

The repository provides selected de-identified interaction excerpts for
reproducibility. It does not publicly release full raw chat transcripts,
participant-level assessment data, identifiable participant records, or
original group-assignment files because these materials contain learner
interaction and assessment data subject to privacy and consent constraints.
